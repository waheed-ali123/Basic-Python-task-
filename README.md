# Python Basics Assignment

Solutions to a 5-part Python assignment covering loops, strings, lists, and control flow.

## 📁 Files

| File | Description |
|---|---|
| `q1_student_marks.py` | Takes marks for 5 subjects, calculates total, percentage, grade, and pass/fail |
| `q2_student_name.py` | Takes a student's name, shows uppercase, lowercase, length, first & last character |
| `q3_number_stats.py` | Takes 10 numbers, calculates sum, average, max, min, and count of even/odd numbers |
| `q4_atm_program.py` | Simple ATM simulation with check balance, deposit, withdraw, and exit |
| `q5_multiplication_tables.py` | Takes a number `n` and prints multiplication tables from 1 to `n` |

## ▶️ Requirements

- Python 3.x (no external libraries needed)

## 🚀 How to Run

Clone the repo, then run any script individually:

```bash
git clone <your-repo-url>
cd <your-repo-name>
python3 q1_student_marks.py
python3 q2_student_name.py
python3 q3_number_stats.py
python3 q4_atm_program.py
python3 q5_multiplication_tables.py
```

## 📝 Question Details

**Q1 — Student Marks**
- Loops 5 times to collect subject marks (input validated 0–100)
- Outputs total marks, percentage, letter grade, and pass/fail (pass if ≥ 50%)

**Q2 — Student Name**
- Accepts a name and outputs uppercase/lowercase versions, character count, first character, and last character

**Q3 — Number Stats**
- Loops 10 times to collect numbers
- Outputs sum, average, largest, smallest, even count, and odd count

**Q4 — ATM Program**
- Starts with a balance of 50,000
- Menu-driven loop (Check Balance / Deposit / Withdraw / Exit) that keeps running until the user chooses Exit
- Validates withdrawal against insufficient funds and rejects negative amounts

**Q5 — Multiplication Tables**
- Takes a positive integer `n`
- Prints multiplication tables (1–10) for every number from 1 to `n`
