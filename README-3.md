# Python Lab Tasks: Dictionaries and Sets

Solutions to two Python lab tasks.

## Files
- `dictionary_tasks.py` – 4 dictionary questions (counting, finding toppers, swapping keys/values, grouping words)
- `set_tasks.py` – 6 set questions (creating sets, removing duplicates, add/remove, membership check, set length, set operations)

## How to Run
```bash
python dictionary_tasks.py
python set_tasks.py
```
`set_tasks.py` asks you to enter a number in Question 4 (try 20 and 99).

## Sample Output (dictionary_tasks.py)
```
{2: 3, 3: 2, 5: 2, 8: 1}
Sara 95
Ahmed 95
{1: 'a', 2: 'b', 3: 'c'}
{'a': ['apple', 'ant'], 'b': ['banana', 'ball'], 'c': ['cat']}
```

## Notes
- Q1 (dict) counts without using `count()`.
- Set Q5: the length is 4 because sets keep only unique elements.
- Set Q6: `A - B` and `B - A` differ because difference depends on which set comes first.
